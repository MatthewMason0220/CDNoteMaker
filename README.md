# CDNoteMaker
Custom note making tool for my work.

I created this GUI to help speed up my note taking process and to generate the template for emails and the details for the change of concerns on files.

This is made entirely in AutoHotKey V2 and has a bunch of really interesting ideas and examples of how things can be used. 

Some code is not my own and copied from other people. In those sections of code there is a comment at the top with the URL and the creators name.

I use visual studio code with the 'AHK++ (AutoHotkey Plus Plus)' extension to make editing easier.
